Painel do Desenvolvedor: Como funciona o JSON e as Requisições?

1. O que é JSON?

JSON (JavaScript Object Notation) é um formato leve de troca de dados estruturado puramente em texto. Ele organiza as informações em pares de "chave": "valor" (ex: "localidade": "São Paulo"), permitindo que diferentes sistemas e linguagens de programação conversem de forma simples e universal.

2. Como a requisição funciona no navegador?

O navegador utiliza a API fetch() para enviar um pedido assíncrono (em segundo plano) para a internet — neste caso, para o servidor do ViaCEP. Essa comunicação assíncrona busca e traz a informação necessária sem recarregar a tela atual, mantendo a experiência de uso fluida e ininterrupta.

3. Como o JavaScript utiliza a resposta?

A resposta bruta retornada da internet chega apenas como texto corrido. Quando executamos o método .json(), o JavaScript lê e converte esse texto de forma automática em um objeto nativo do código. A partir desse momento, conseguimos acessar propriedades específicas diretamente através do ponto (ex: dados.localidade).
